Password Generator

Buat sandi acak dengan panjang 6–64 karakter, memakai crypto.getRandomValues. Sandi tidak dikirim ke server dan tidak disimpan.

Langkah pemakaian

  1. Buka Zenkai Tools, tekan kartu Password Generator.
  2. Atur panjang (minimal 12 untuk keamanan).
  3. Pilih jenis karakter: huruf besar, huruf kecil, angka, simbol.
  4. Tekan Generate Password.
  5. Tekan Salin Password, simpan di password manager.

Batasan

  • Minimal satu jenis karakter harus dipilih.
  • Tidak menyimpan riwayat. Salin sebelum menutup modal.
  • Panjang di atas 32 karakter bisa ditolak sebagian layanan yang membatasi panjang.

FAQ

Apakah password disimpan di server?

Tidak. Password dibuat langsung di perangkat kamu lewat Web Crypto API. Tidak ada permintaan jaringan yang mengirim hasil sandi.

Berapa panjang password yang aman?

Minimal 12 karakter dengan campuran huruf besar, huruf kecil, angka, dan simbol. Semakin panjang, semakin kuat.

Kalau saya tutup halaman, sandinya hilang?

Ya. Password hanya ditampilkan sekali. Salin atau simpan dulu sebelum menutup halaman.
