Masuk dengan Login Resmi Google — sistem autentikasi asli dari Google (Google Identity Services), bukan login buatan kami.

Kami tahu Zenkai Tools masih terbilang baru, dan wajar kalau kamu belum sepenuhnya percaya. Karena itu kami pakai login resmi Google — supaya kamu bisa lihat sendiri bahwa password kamu tidak pernah lewat tangan kami.

Kalau masih ragu, silakan pakai akun Gmail kecil / akun cadangan kamu. Tidak masalah sama sekali. Yang penting kamu bisa masuk dan pakai tool-nya.

  • Password Google kamu tidak pernah melewati server Zenkai.
  • Kami hanya menerima email dan nama tampilan dari Google.
  • Tanpa password baru, tanpa OTP, tanpa email verifikasi.

Ditambah lagi, kami pasang Cloudflare Turnstile — verifikasi keamanan yang sama dipakai jutaan situs besar di dunia, untuk memastikan yang masuk benar-benar manusia, bukan bot.

Login Resmi dari Google & Cloudflare — standar keamanan global.

Catatan: Login cukup sekali per perangkat. Setelah masuk, kamu bebas pakai semua tool tanpa login ulang. Kalau mau logout, klik avatar di pojok kanan atas.

Tentang Zenkai Tools

Aplikasi web utilitas yang menyediakan alat bantu (downloader, generator, stalker) gratis tanpa instalasi. Dibuat untuk kebutuhan harian: menyimpan video, membuat QR, mengubah format gambar, dan sejenisnya.

Fitur Baru

  • Alat Stalk MLBB untuk lacak profil Mobile Legends.
  • AI Image Editor V2 - edit gambar via GPT-Image.
  • NoTrack AI Chat - chat AI dengan dukungan gambar.
  • Peningkatan alur Alight Motion Premium dengan verifikasi link terbaru.

Privasi

Policy

Kebijakan Privasi

Ringkasan: Zenkai Tools tidak meminta akun, tidak memasang iklan pop-up, dan hanya memproses data yang kamu kirim ke endpoint alat tertentu.

Data yang diproses

  • URL atau teks yang kamu tempel ke kolom alat (dikirim ke server kami untuk diproses).
  • Preferensi lokal (tema, volume) disimpan di localStorage browser kamu.
  • Tidak ada akun wajib, tidak ada pelacakan lintas situs oleh kami.

Pihak ketiga

Beberapa alat memanggil API pihak ketiga (Supabase, YouTube, dsb). Data yang diproses tunduk pada kebijakan privasi masing-masing layanan.

Penghapusan data

Gunakan tombol "Hapus Cache Web" di halaman Setelan untuk menghapus preferensi lokal. Untuk permintaan khusus, hubungi andikatalovamartin@gmail.com.
